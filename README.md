# 🐱 Super Cat Typing Adventure

A vibrant, kid-friendly typing game designed for 7-year-olds to practice and master their keyboard skills through playful reinforcement.

## ✨ Features
- **Dynamic Themes:** Level background colors change as the score increases.
- **Visual Feedback:** Correctly typed characters turn green instantly.
- **Fun Power-ups:** Special words like `freeze` (stops movement), `boom` (clears screen), and `heal` (restores hearts).
- **Retro Sound Effects:** Uses native Web Audio API (no external asset dependencies).
- **Cute Cat Mascot:** Cheers the player on or reacts when a word hits the floor.

## 🛠️ Tech Stack
- HTML5
- CSS3 (CSS Variables & Keyframe Animations)
- Vanilla JavaScript
